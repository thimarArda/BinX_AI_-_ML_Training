# Day 4 — EDA Part 1: Distributions & Outliers

## Overview
This Jupyter Notebook provides an introduction to Exploratory Data Analysis (EDA), focusing specifically on understanding data distributions and identifying outliers. The notebook uses the Medical Insurance Cost dataset `insurance.csv` to demonstrate key EDA concepts and techniques with Python.

The notebook contains concepts that were better articulated in the previous days of this week 2 folder so make sure to check them out if some of them were not clear :)

## Notebook Contents

### Section 1: Learnings
> Mostly Markdowns 

1. EDA definition and importance in data analysis
2. Univariate statistics: central tendency, range, normality, and spread
3. Correlation coefficient and p-values for measuring relationships
4. Seaborn library for statistical visualization
5. Univariate analysis techniques
6. Outlier detection using the IQR (Interquartile Range) method
