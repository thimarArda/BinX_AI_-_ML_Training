# Week 5 — Unsupervised Learning

## Overview

In the previous weeks of this training, the focus was primarily on **supervised learning**, where machine learning models were trained using labeled data to predict a known target or outcome.

This week introduces **Unsupervised Learning**, a different approach to machine learning where the data does not contain predefined target labels. Instead, the goal is to explore the underlying structure of the data and discover meaningful patterns, relationships, and groups.

Unsupervised learning techniques included :

* Clustering
* K-Means Clustering
* The Elbow Method
* Silhouette Analysis
* DBSCAN
* Hierarchical Clustering
* Dimensionality Reduction
* Principal Component Analysis (PCA)

The repository also includes the planning document for **Sprint 1**, which marks the beginning of the project planning and development phase.

## How to Use This Repository


### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Week 5 Folder

```bash
cd Week5_Unsupervised_Learning
```

### 3. Install the Required Libraries

Make sure Python and Jupyter Notebook are installed, then install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

### 4. Open Jupyter Notebook

```bash
jupyter notebook
```

Then open the notebook corresponding to the day or topic you would like to explore.

### 5. Follow the Learning Progression

For the best learning experience, it is recommended to go through the materials in chronological order:

1. Start with **Day 1** to understand the foundations of unsupervised learning and clustering.
2. Continue through the following days to explore different clustering techniques and methods for evaluating clusters.
3. Study **PCA and dimensionality reduction** to understand how high-dimensional data can be simplified while preserving important information.
4. Review the **Sprint 1 Planning** file to see the beginning of the project planning process.
