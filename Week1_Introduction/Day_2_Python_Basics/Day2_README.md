# Day 2 - Python Basics 🐍

## What this is about
This notebook is just practicing the core Python skills before jumping into NumPy, Pandas, and Matplotlib. It covers functions, list comprehensions, and a small intro to classes (OOP).

## What the notebook does
1. **Writes functions from scratch** (`min_number`, `max_number`, `mean_number`) that calculate the min, max, and average of a list of numbers manually, instead of using built-in math functions, just to get comfortable with the syntax.
2. **Combines those functions** into one function (`list_to_dict`) that returns the mean, min, and max as a dictionary.
3. **Rewrites a for-loop as a list comprehension**, filtering out even numbers from a list in one line instead of a multi-line loop.
4. **Builds a small class** called `Age` that takes a name and age, and has a method that checks if the person is a teenager or not.

## Tools used
- Python
- Jupyter Notebook

## How to run it
Just open the notebook and run the cells from top to bottom, no dataset or extra libraries needed for this one.
