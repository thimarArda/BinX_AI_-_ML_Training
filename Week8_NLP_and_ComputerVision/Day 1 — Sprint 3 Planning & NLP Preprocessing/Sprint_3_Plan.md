# Sprint 3 Planning — Banking Customer Support Chatbot

## Sprint Goal

Improve the banking dialogue chatbot developed in Sprint 2 by building a complete NLP preprocessing pipeline, integrating it with the existing Transformer model, and performing a full evaluation of the model.

## Sprint Backlog

- [ ] Review the Transformer-based banking chatbot developed in Sprint 2.
- [ ] Inspect and prepare the banking dialogue dataset.
- [ ] Implement text preprocessing and normalization.
- [ ] Apply tokenization, lowercasing, punctuation removal, and appropriate stop-word handling.
- [ ] Apply lemmatization and evaluate whether it preserves important information for the chatbot.
- [ ] Experiment with TF-IDF and word embeddings as text representations.
- [ ] Integrate the preprocessing pipeline with the existing Transformer model.
- [ ] Evaluate the model using accuracy, precision, recall, and F1-score.
- [ ] Generate a confusion matrix and classification report.
- [ ] Perform error analysis on incorrectly classified customer messages.
- [ ] Identify possible improvements based on the evaluation results.
- [ ] Build a clean end-to-end pipeline from user input to model prediction.
- [ ] Document the methodology, results, limitations, and improvements.
- [ ] Prepare the final results for the Sprint 3 Review.

## Expected Outcome

By the end of Sprint 3, the banking chatbot should have a complete and documented NLP pipeline that processes customer messages, passes them through the Transformer-based model, produces predictions, and provides a thorough evaluation of its performance.
